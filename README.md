# PhantomCam - Research Tool for Browser Security

**Disclaimer:** This tool is designed for educational and security research purposes only.  
It demonstrates how headless browsers can access media devices without triggering permission dialogs in certain Chromium versions.

## Features
- Automated webcam frame capture
- Telegram API integration for data exfiltration testing
- Randomized file naming for anonymity
- Permission bypass via Chromium flags (research only)
